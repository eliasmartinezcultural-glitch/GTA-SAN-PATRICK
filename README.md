# GTA SAN PATRICK

## Prototipo 0.1

Primer prototipo jugable de un mundo abierto inspirado en la filosofía de **GTA San Andreas**, pero creado alrededor de **San Patricio del Chañar, Neuquén**.

### Qué demuestra
- Mundo 3D en navegador.
- Cámara en tercera persona.
- Personaje masculino.
- Movimiento con WASD o flechas.
- Calles, edificios, árboles, viñedos, río y bardas como lenguaje visual local.
- Arquitectura preparada para crecer hacia vehículos, NPC, misiones, economía, propiedades y actividades.

### Identidad del territorio
El paisaje inicial toma como referencia elementos documentados del Chañar: valle irrigado, río Neuquén, bardas, viñedos, frutales, alamedas y caminos rurales. La geometría actual es **prototipo artístico**, no un mapa cartográfico exacto. La siguiente etapa debe convertir el territorio real en un mapa jugable más preciso.

### Regla de desarrollo
**Chañar no es decoración. Chañar es el mundo.**

Tecnología: HTML + CSS + JavaScript + Three.js por CDN.  
Hosting previsto: GitHub Pages.
